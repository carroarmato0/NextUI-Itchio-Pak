## Itch-io v1.1.1

A small release that adds diagnostics and changes nothing you will see. It helps
us track down why some players get **HTTP 403** on every game page
([issue #9](https://github.com/carroarmato0/NextUI-Itchio-Pak/issues/9)).

### Refused requests can now be traced

When itch.io refuses a request, the log now records the details itch.io needs
to find that exact request on their side:

```
[WARN]  client: GET creator.itch.io/game -> HTTP 403 ray=a57f…-CDG mitigated=challenge server=cloudflare date="Mon, 09 Nov 2026 11:19:35 GMT"
```

- `ray` is Cloudflare's ID for the request.
- `mitigated` says whether a bot challenge stopped it.
- `date` is the server's time in UTC, which the device's own timestamps are not.

Only the address and path are logged. Query strings are never logged, because
download links carry their access tokens there. "Not found" responses are left
out, since they are routine and never a block.

**If you get "HTTP 403" in the app**, update, reproduce it once, and attach
your `itchio.log` to an issue. The lines starting with `client:` are the useful
ones.

### Under the hood

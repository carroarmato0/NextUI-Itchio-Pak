# my355 Polish Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix three my355-specific polish issues: footer text overflow on narrow (640px) screens, d-pad double-input on my355, and tag overflow in the list-screen right panel (all platforms).

**Architecture:** All changes are self-contained to three files. The footer fix is a width-branch at draw time. The double-input fix is a scancode deduplication map injected into the event loop before any screen code runs. The tag fix replaces the per-tag loop with a comma-joined, wrapped, vertically-scrolling block.

**Tech Stack:** Go 1.22+, SDL2 via `github.com/veandco/go-sdl2`, renderer package (`internal/renderer`), ui package (`internal/ui`).

## Task 3: Double-input deduplication on my355

**Files:**

```go
for current != nil {
    cache.ProcessPending(r)

    for e := sdl.PollEvent(); e != nil; e = sdl.PollEvent() {
        current = current.HandleEvent(e)

```

- [ ] **Step 2: Read platform and build the dedup map before the loop**

Add just before the `for current != nil {` line:

```go
platform := readPlatform()
var pressedScancodes map[sdl.Scancode]bool
if platform == "my355" {
    pressedScancodes = make(map[sdl.Scancode]bool)
}
```

- [ ] **Step 3: Wrap event dispatch with dedup filter**

Replace:

```go
for e := sdl.PollEvent(); e != nil; e = sdl.PollEvent() {
    current = current.HandleEvent(e)
    if current == nil {
        break
    }
}
```

With:

```go
for e := sdl.PollEvent(); e != nil; e = sdl.PollEvent() {
    if pressedScancodes != nil {
        if kev, ok := e.(*sdl.KeyboardEvent); ok {
            sc := kev.Keysym.Scancode
            if kev.Type == sdl.KEYDOWN {
                if pressedScancodes[sc] {
                    continue // duplicate KEYDOWN — drop it
                }
                pressedScancodes[sc] = true
            } else if kev.Type == sdl.KEYUP {
                delete(pressedScancodes, sc)
            }
        }
    }
    current = current.HandleEvent(e)
    if current == nil {
        break
    }
}
```

```go
    }
```

Replace with:

```go
// Tags: filter, comma-join, wrap to panel width, vertical-scroll if overflow.
var filteredTags []string
for _, tag := range g.Tags {
    if strings.EqualFold(tag, "free") {
        continue
    }
    if len(tag) > 0 && strings.ContainsRune("$€£¥", rune(tag[0])) {
        continue
    }
    filteredTags = append(filteredTags, tag)
}
if len(filteredTags) > 0 {
    tagLine := strings.Join(filteredTags, ", ")
    wrappedLines := r.WrapText(tagLine, rightW)
    wrappedH := int32(len(wrappedLines)) * lineGap
    availH := r.H - footerH - metaY
    if wrappedH <= availH {
        // Fits — draw statically.
        for _, line := range wrappedLines {
            r.DrawText(line, rightX, metaY, 120, 180, 220)
            metaY += lineGap
        }
    } else {
        // Scrolling render.
        maxTagScroll := wrappedH - availH
        if s.tagScrollY > maxTagScroll {
            s.tagScrollY = maxTagScroll
        }
        // Reset after pause at bottom (same logic as title scroll).
        if s.tagScrollY == maxTagScroll &&
            time.Since(s.tagScrollAt) > scrollDelay+time.Duration(maxTagScroll)*time.Second/time.Duration(tagScrollSpeed)+time.Second {
            s.tagScrollY = 0
            s.tagScrollAt = time.Now()
        }
        r.SetClipRect(rightX, metaY, rightW, availH)
        drawY := metaY - s.tagScrollY
        for _, line := range wrappedLines {
            r.DrawText(line, rightX, drawY, 120, 180, 220)
            drawY += lineGap
        }
        r.ClearClipRect()
    }
}
```

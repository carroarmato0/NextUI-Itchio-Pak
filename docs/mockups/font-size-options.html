Implementation notes
All three options are a single-line change in internal/renderer/renderer.go:
Option A (current): fontSize := h / 32 → ~24px at 768
Option B (recommended): fontSize := h / 22 → ~35px at 768
Option C (large): fontSize := h / 18 → ~43px at 768

Row heights, header height, footer height, and Y offsets all scale automatically because most layout values already use the renderer dimensions (r.H, r.W) — but the list row height (rowH = 32) and settings item spacing are hardcoded and would need adjusting to match the chosen font size.
